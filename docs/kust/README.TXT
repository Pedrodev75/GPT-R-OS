KUST 0.1 - GPT-R OS

Kust e uma linguagem compilada com tipagem estatica.
O compilador nativo fica em /SYS64/KUST.APP.
Ele gera aplicativos GTRA v1.1.

Primeiro programa: kust docs START
Comandos: kust help

Capitulos: START, SYNTAX, TYPES, FLOW, FUNCS,
API, ERRORS, LIMITS e CLI. Use kust docs CAPITULO
ou kust docs CAPITULO PAG para uma pagina.
No Explorador, abra /SYS64/DOCS/KUST e selecione
um TXT para ler no Editor.

EXAMPLES contem HELLO, VARIABLE, MATH, FLOW,
FUNCS, FILES, MEMORY e GRAPHIC. Todos usam .KST.
